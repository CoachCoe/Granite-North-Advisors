  "ADVISORS": Source Sans 3 SemiBold, +32% tracking
  Text in the SVGs is converted to outlines, so no fonts need installing.

FOLDERS
  mark/    the symbol alone (color, reversed for dark backgrounds, black, white)
  logo/    horizontal and stacked logos with the name

  social/  LinkedIn avatar (dark and light), LinkedIn banner

USE
  - Use the reversed versions on dark backgrounds.
  - Keep clear space around the logo at least the height of the north star.
  - Don't stretch, recolor outside these palettes, or add effects.
  - The web favicons use a slightly heavier line so they stay crisp at 16 px.
